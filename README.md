This public repository stores a JSON config that [Global Speed](https://github.com/polywock/globalSpeed) can read to promote some of my side projects.

Global Speed may fetch this static file over [jsDelivr](https://www.jsdelivr.com/), a CDN that caches GitHub files. Nothing about the user is sent.

```
https://cdn.jsdelivr.net/gh/polywock/gs-promos@main/config.json
```
